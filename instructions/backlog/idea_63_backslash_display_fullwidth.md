# idea_63_backslash_display_fullwidth.md

## 概要

**キー名の表示で、半角の `\` を全角の `＼`（U+FF3C）に替え、¥ と見分けられるようにする。** 日本語のフォントは半角の `\`（U+005C）を ¥ の形で描くため、`ro`（ろ キー）・`backslash` と `yen`（¥ キー）が画面で同じ ¥ に見える。保存するキー名は変えず、表示だけを替える。

## 起票経緯（2026-11-22）

出所: phase 75 task_13 の Windows 実機確認（exe）の際のユーザー要望。キーボードUIのレイアウトを US のまま ろ キーを置換先に記録したところ `backslash` で保存され、Shift と押すと `|` が出た（key_input.md の受容どおり）。表示が ¥ だったため原因に気づきにくかった。

## 現状

- 表示の表は `keyseq/domain/key_symbols.py` の `KEY_SYMBOLS`（`"backslash": "\\"`・`"ro": "\\"`・`"yen": "¥"`）。phase 74 の記号キーのキー名の表示（表 36 個）。
- 正本: `instructions/common/spec_detail/ui_terms.md`（キー名の表記）・`key_input.md`（JIS の特殊キーの受容）。
- `tk_keys.py:73` は `KEY_SYMBOLS` を文字からの名前の逆引きにも使っている（表示の文字を替えると逆引きに影響し得る・要確認）。

## 提案（方向性・要設計）

- 案 A: `ro` / `backslash` の表示を `＼`（全角）にする。`yen` は `¥` のまま。
- 案 B: `ro` はキーの刻印どおり「ろ」、`backslash` は `＼` にする。
- 逆引き（`tk_keys.py:73`）は表示の表と切り離すか、全角の文字も引けるようにするかを決める。
- 英語表示（en）でも全角にするか（英語のフォントでは半角で問題ない）。
