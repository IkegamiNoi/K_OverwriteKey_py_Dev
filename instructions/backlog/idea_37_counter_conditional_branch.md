# idea_37_counter_conditional_branch.md

## 概要

出力シーケンスの system 種別に**カウンター値による条件分岐**（例: 「カウンター n が N 以上なら停止 / ループを抜ける」）を加える。
主な用途は **file_line で読むファイルの終端でループを止める**こと。
スクリプト言語化を避けるため、条件・動作の種類は最小限に絞る前提。

## 起票経緯（2026-09-26）

ユーザー対話（出力シーケンスへの system 種別の追加）で提案し、「idea に起票しておく程度で」と合意。
暫定仕様 [26](../history/26_sequence_control_actions.md)（phase 37・第 1 弾）と第 2 弾（停止・他トリガー呼び出し）のスコープ外。

## 現状

- 暫定 26 で system（ループ / カウンター +1・0 に / 待機 / 戻す / 先頭へ）と file_line を導入予定。
  ループは回数指定か無限のみで、途中で抜ける手段は無い（第 2 弾の「停止」は連続実行を区切るだけ）。
- file_line の範囲外は「エラーで停止 / 空を送る / 折り返し」の 3 択（暫定 26 §9）。エラー停止で終端検出の代用はできる。

## 提案（方向性・要設計）

- 案 A: 「カウンターが N 以上ならループを抜ける」（break）だけを加える。最小。
- 案 B: 「条件を満たしたら停止」（第 2 弾の停止と組み合わせる）。
- 案 C: N の代わりに「file_line のファイルの行数」を比較対象に選べるようにする（終端検出に直結）。
- ジャンプ（任意位置へ）は暫定 26 §2-13 で不採用。分岐先を任意位置にする案は採らない方向。

## 想定スコープ

- 含む: system の op 追加・編集ダイアログ・一覧表示・実行規則。
- 含まない: 変数の演算・複合条件・任意位置へのジャンプ。
- 仕様変更あり（`data_schema.md` §5.11 / `features.md` §4.2）。第 2 弾の完了後に要否を判断。
