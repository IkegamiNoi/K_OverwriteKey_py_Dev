# idea_56_more_ui_languages.md

## 概要

**画面の言語を日本語・英語以外にも増やす**（3 言語目以降）。phase 72 で作る仕組み（言語ファイルを置くと一覧に出る）を使い、
言語ごとに文言ファイルとヘルプ本文を足す。

## 起票経緯（2026-11-01）

phase 72（多言語対応）の範囲を決めるときに、まず日本語・英語の 2 つで作り、3 言語目以降は別にするとユーザーが決めた
（[暫定 55](../history/55_multilingual_ui.md) §2・§10）。

## 現状

- phase 72 で `keyseq/shared/i18n/locales/<code>.json` と `presentation/help/content/help_<code>.json` を置くと
  言語の一覧に出る仕組みになる予定（訳の無い文言は英語で出る）。

## 提案（方向性・要設計）

- 足す言語の選定と翻訳の作り方（誰が訳し、どう確かめるか）。
- 言語ごとの見え方の確認（文字の長い言語〔ドイツ語等〕での幅・CJK のフォント）。
- 言語ファイルの完全性テストを全言語へ広げるか（足りないキーは英語で出るので必須ではない）。

## 想定スコープ

- 含む: 言語ファイル・ヘルプ本文の追加・見え方の確認。
- 含まない: 右から左に書く言語。
- 影響レイヤ: 同梱データのみの見込み（コードの変更は不要な想定）。仕様変更は対応言語の列挙程度。
