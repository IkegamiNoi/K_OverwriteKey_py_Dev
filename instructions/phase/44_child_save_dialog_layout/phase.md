# phase.md

## フェーズ名

子ファイル保存ダイアログの高さと列幅の調整（child_save_dialog_layout）

## フェーズの目的

構成セットの保存で出す子ファイル一覧ダイアログを、**行数に合わせた高さ**で開き、**列の境界をドラッグで調整**でき、
**ウィンドウを広げたときは保存先パスだけが広がる**ようにする。
**presentation のみ（`controllers/config_io/child_save_dialog.py`）・domain / application 不変・JSON スキーマ変更なし（列幅は保存しない）。**

- 起票元: ユーザー要望（2026-10-04・「ファイル数に対して縦方向に長すぎることがある / 表示の種別をスプリッターで調整したい / 枠を広げたときにファイルパスの幅が調整されるようにしたい」）。
- 主入力（暫定仕様）: なし（直接改訂モード）。改訂先 = `features.md` §4.6「子ファイル保存ダイアログ」。
- モード: **直接改訂モード**。番号対応: phase 44 / 暫定なし / decisions 44。

## 確定（ユーザー 2026-10-04）

- **高さ**: 開いたときの高さは見出し + 全行 + ボタンが収まる高さ。上限は**画面の高さの 6 割**で、超えたら縦にスクロールする（現行の固定 960×480・最小の高さ 320 をやめる）
- **列の境界のドラッグ**: 列は「種別 | 対象名 | 保存先パス | 共有状況 | 操作」。ドラッグできる境界は **種別|対象名・対象名|保存先パス・保存先パス|共有状況 の 3 つ**。
  どの境界を動かしても**増減の差は保存先パスが受け持つ**（共有状況は左の境界で広げ、保存先パスから幅を取る）。**操作（ラジオボタン）列は固定幅**
- **ウィンドウを広げた / 狭めたときは保存先パスだけが伸び縮みする**（対象名は伸びない）
- **列幅は保存しない**（開くたびに既定の幅）
