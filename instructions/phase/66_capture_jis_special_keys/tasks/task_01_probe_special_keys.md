# task_01_probe_special_keys

## 目的

暫定 49 §7a の実測。4 キー（半角/全角・無変換・変換・かな）と、押下だけで届くキーボードの無変換・変換が、keyboard のフックにどの走査コード・`event_type` の並びで届くかと、抑止したときに IME がどう切り替わるかを測り、§3-4・§3-5 の「押下中を外す一定時間」と「余韻の上限」の値を決める。
**実測のみ・アプリのコード変更なし**（測定用の小スクリプトはスクラッチに置き、リポジトリへ入れない）。

## 対象範囲（実測のみ）

- 測定用の窓（`.venv`・Tk の窓 1 つ・keyboard の `hook(suppress=True)`・時間で自動終了）: フックのイベント（時刻・`event_type`・`scan_code`・`name`・`is_keypad`）と、窓の IME の開閉（`own_ime_status.get_open_status`・100 ms ごと）を記録する。抑止の方式を窓のボタンで切り替える（素通し / 押下と離しを抑止 / 押下だけ抑止）。抑止の対象は走査コード 41・112・121・123・241・242 だけで、他は True を返して素通し
- ユーザーが実機で、各方式について 4 キーを「1 回押して離す」「長押しして離す」を行う（押下だけのキーボードがあればそれも）
- 結果を暫定 49 §7a へ書き、§3-4・§3-5 の値を決めて版を上げる（ユーザー確認）

- §3-4・§3-5 の値が暫定 49 に書かれ、ユーザーが確認した
