### 実機目視チェックリスト

事前: アプリを終了し、`config/config.json` をバックアップしておく（2・6 で書き換えるため）。

1. **ヘッダが切れない**: フォント −3 / 標準 / ＋3 のそれぞれで、ウィンドウの縁を左へ最小までドラッグ → フック / 表示 / ファイルの枠の中身が切れない。
2. **起動時の幅**: `config.json` から `full_view_window_width` を消して起動 → 780 より少し広く（標準で約 +19px）開き、ヘッダが切れない。何もせず終了 → `full_view_window_width` が書かれていない。
3. **取得ボタン**: 「キー入力で取得」を押す → 「取得中…（Escで停止）」になってもボタン幅・ヘッダが動かない（Esc で戻る）。フック開始 / 通常トリガー切替を押しても同様。
4. **ドロップダウン**: キーボード選択の欄がフル表示・省略表示とも以前より狭く、選択肢（US TKL 等）が読める。
5. **＋3**: フォントを ＋3 にする → ヘッダに合わせてウィンドウが広がる。標準に戻す → ウィンドウは縮まないが、縁で縮められる。
6. **旧保存値が狭い場合**: アプリ終了中に `full_view_window_width` を `700` に書き換えて起動 → 最小幅まで広がって開き、`config.json` の値が開いた幅に更新されている。
7. **ドラッグ後**: 出力シーケンスの境界線をドラッグして離す → 縁で最小まで縮めてもキーマップ管理・出力シーケンスの幅が変わらず、ヘッダも切れない。
8. **省略表示**: 省略表示へ切り替え → 幅 270 のまま。フル表示へ戻る → 元の幅・配置に戻る。

終了後: `config.json` をバックアップから戻す（任意）。
