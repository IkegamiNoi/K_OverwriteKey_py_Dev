# task_16_save_dialog_initial_fit_and_wheel

## 目的

子ファイル保存ダイアログの表示不具合 2 件を直す（暫定仕様 05 **v0.5-L** / **v0.5-M**・§3-5・受入条件 **22**）。

1. **【L】初期表示で対象名・保存先パスが「…」だけになる**。省略の再計算は canvas の `<Configure>` でのみ走り
   **同幅なら早期 return** する（`child_save_dialog.py:125-140`。task_11 の再入防止）。初回 Configure の時点では
   各セルがまだレイアウトされておらず `winfo_width()` が 1px 相当のため全省略になり、同じ幅の Configure では復旧しない。
2. **【M】スクロール領域上でマウスホイールが効かない**。`<MouseWheel>` を canvas 本体にだけバインドしており
   （`:54-57`）、Tk のバインドは親から子へ伝播しないため、行のラベル・ラジオの上では無反応。

レイヤ制約: **presentation 限定・`config_io/child_save_dialog.py` のみ**。
**application / domain 不変・スキーマ不変・保存挙動は一切変えない**（表示とイベントのみ）。

## 対象範囲（`child_save_dialog.py` 限定）

### 1. 初期表示の省略計算（v0.5-L）

- **`<Configure>` の早期 return（同幅なら何もしない）は維持する**（再入・無限ループ防止＝ task_11 の不変条件）。
- **初期レイアウト確定後に 1 回だけ、幅キャッシュを無効化して再計算する**。
  実装は `_create_action_dialog` の最後（`_set_minimum_size` の後）で `after_idle` 等を使い、
  `last_width` をリセットしてから再計算を走らせる形を想定する（`_bind_content_width` が
  再計算関数と無効化手段を返す等、実装者判断でよい）。
- 再計算時に**セル幅がまだ確定していない**（`winfo_width() <= 1`）場合は、
  その回の結果を**キャッシュに焼き付けない**こと（次の機会に正しい幅で再計算できる状態を保つ）。
- 省略量が幅に追随する挙動（v0.4-C 追記）・`_fit_text` / `_ellipsize` / `_ellipsize_path` の
  アルゴリズムは**変更しない**。

### 2. マウスホイール（v0.5-M）

- **スクロール領域内のどのウィジェット上でもホイールで縦スクロールできる**ようにする。
  Tk のバインドは親→子へ伝播しないが、**子で発生したイベントは Toplevel のバインドタグへ伝播する**ため、
  `dialog`（Toplevel）へ `<MouseWheel>` をバインドする方法を第一候補とする。
- `bind_all` を使う場合は**ダイアログ破棄時に確実に解除**すること（他ウィンドウへ影響を残さない）。
  Toplevel バインドなら破棄で自動的に消えるため、そちらを推奨。
- スクロール量の計算は現行式（`-int(event.delta / 120)` units）を踏襲する。
- 依存確認ダイアログ・A2 ダイアログ（スクロールを持たない）には**足さない**。

### 3. テスト（`tests_ui/test_child_save_dialog.py`）

**新規ファイルは作らない**。既存の構造テストの作法（ウィジェットを実際に生成して数値で判定）に合わせる。

| # | 内容 |
|---|---|
| 1 | **受入条件 22**: ダイアログを表示した直後（リサイズなし）に、対象名・保存先パスの各セルの表示文字列が **`"…"` 単独ではない**（長い文字列でも先頭または末尾の実文字を含む） |
| 2 | 幅を変えると省略量が変わる（task_11 の既存テストがあれば流用・重複追加はしない） |
| 3 | **受入条件 22**: スクロール領域内の**子ウィジェット**（行のラベル）に対して `<MouseWheel>` を `event_generate` すると、canvas の `yview()` の先頭値が変化する（行数を十分に用意してスクロール可能な状態にする） |
| 4 | ダイアログ破棄後にホイールのバインドが残らない（`bind_all` を使わない実装ならバインドタグの確認、使う場合は解除の確認） |

- 既存の **fail-fast ガード**（`showerror` / A2 / 依存確認が呼ばれたら `AssertionError`）を壊さないこと。

### 設計メモ / 制約

- `child_save_dialog.py` は現在 **360 行**（目安 300 行超）。本タスクでの**分割はしない**
  （`/refactor_check` の申し送り事項のまま。task 途中で構造変更をしない＝ `anti_patterns.md` 2）。
  行数が増えるなら既存の補助メソッド（`_add_text_cell` / `_bind_content_width` 等）へ寄せる。
- `_set_minimum_size` の算出（`minsize` を要求幅から決める）は**変更しない**。
- 「初期表示で 1 回だけ再計算」は**タイマー連打で誤魔化さない**（`after(100)` の繰り返し等は不可）。
  イベント駆動（`after_idle` / `<Map>`）で 1 回にとどめる。
