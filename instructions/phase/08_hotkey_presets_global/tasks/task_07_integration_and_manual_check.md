| 2 | **編集が即時にファイルへ入る**（受入条件 3）| プリセットを編集して OK → **keymap_set を保存せずに**アプリを終了 → 再起動 | 編集内容が**残っている**（`config/user/hotkey_presets/default.json` が更新済み）|
