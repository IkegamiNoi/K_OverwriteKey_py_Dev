# task_07_integration_check

## 目的

**phase 09 の実装（task_01〜06）を通しで確認し、受入条件 1〜18 の充足を判定する**
（暫定仕様 08 **§5 受け入れ条件**）。実装タスクは task_06 で出揃っており、
**本タスクでコードは原則変更しない**（**実機目視で見つかった不具合の是正のみ**変更してよい）。

**是正が仕様変更を伴う場合は枝番タスクへ切り出す**（既実績: task_07b =【O4】/
**task_07c・07d・07e = v0.8 の 3 改訂**）。本タスクは**通し確認と実機目視の実施**に徹する。

**レイヤ制約**: 是正が必要になった場合も**最小差分**。設計変更が要るなら
`.claude/rules/spec_change_workflow.md` に従い**ユーザー判断を仰ぐ**（独断で仕様を緩めない）。
