# task_07_integration_check

## 目的

**phase 09 の実装（task_01〜06）を通しで確認し、受入条件 1〜17 の充足を判定する**
（暫定仕様 08 **§5 受け入れ条件**）。実装タスクは task_06 で出揃っており、
**本タスクでコードは原則変更しない**（**実機目視で見つかった不具合の是正のみ**変更してよい）。

**レイヤ制約**: 是正が必要になった場合も**最小差分**。設計変更が要るなら
`.claude/rules/spec_change_workflow.md` に従い**ユーザー判断を仰ぐ**（独断で仕様を緩めない）。

## 対象範囲

phase 全体の差分（**`39140c5..HEAD`** = task_01 直前〜task_06）に対して通しで再実測する。

- `-m compileall -q keyseq main.py tests tests_ui` が clean
- `-m unittest discover -s tests` が **pass**（現行 **225**）
- `-m unittest discover -s tests_ui` が **pass**（現行 **202**）
- `-m tests.smoke_app` が pass

### 2. 二次レビュー（**2 本立て・省略しない**）

`.claude/rules/agent_selection.md` の「フェーズ完了判定前」に従う。
**phase 08 では両者が独立に起動不能バグを検出した**ため、片方だけで確定させない。

- **`deep-reviewer`**（Claude 側）— 対象は **`39140c5..HEAD`** の差分と暫定仕様 08 v0.6 の整合
- **`codex-adversarial-reviewer`**（Codex 側）— 同じ差分に敵対的レビュー
- 指摘は**提示のみ**。採否は**ユーザー確認**を経て決める
