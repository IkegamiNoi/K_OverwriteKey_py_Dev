## 対象範囲

### 実機目視（ユーザー）

準備: アプリを起動し、構成セットを 1 つ読み込んでフックを開始しておく。

**ヘルプの窓**
1. メニュー「ヘルプ」に「使い方」「よくある質問」・区切り・「バージョン情報」「ライセンス」がある。メニュー「設定」で文字サイズを変えた後も同じ（§3）
2. 「使い方」で窓が開く → もう一度「使い方」/「よくある質問」を選ぶと、2 つ目は開かず同じ窓が前面に出てタブが切り替わる。窓を開いたままメインの窓を操作できる（§4.1）
3. 大分類・項目はすべて閉じた状態で開く。見出しのクリック・↑↓・Enter / Space で開閉できる。**見出しをダブルクリックしたときの動き**（2 回開閉して元に戻るのが気になるか）（task_07 指摘 4）
4. 読みやすさ: 大分類が太字で、大分類の間・行の間に余白がある。窓を狭くしても「キー置換:」の後で改行されず、箇条書きの 2 行目が「・」ではなく本文の頭に揃う
5. 絞り込み: 語を空白で区切ると AND で絞られ、一致箇所が色付け・タブに件数・一致する項目が自動で開く。一致なしで「一致する項目はありません。」。空白だけ入れたときはタブに件数が付かない。Esc で入力が消え、もう一度 Esc で窓が閉じる（§4.3）
6. 絞り込みの入力欄をクリックするとフックが一時停止し（ステータスで確認）、本文をクリックする・窓を閉じると元に戻る。窓を開いただけでは止まらない（§4.4）
7. 文字サイズの変更が、開いているヘルプの窓（太字の見出しを含む）にすぐ反映される（§4.5）
8. メニューの「最前面に表示」を ON / OFF したとき、ヘルプの窓も追従する。キーボードUIを最前面で開いている場合、ヘルプとの重なりが不自然でない（§4.1）

**ダイアログの「?」（§6）**
9. 例として「トリガーの追加・編集」「キーマップの編集」「未使用ファイルの整理」で、下端のボタン列の左端に「?」がある（ツールチップ「ヘルプ」）。押すと該当の大分類が開いた状態でヘルプが出て、ダイアログとヘルプの両方を操作できる。ダイアログを閉じるとヘルプも閉じる

**コピー（task_07 指摘 1・3）**
10. フックを ON のまま、ヘルプ本文・ライセンスの窓・バージョン情報で、選択 → Ctrl+C と右クリック「コピー」ができる（キーマップで c や Ctrl を置き換えていると化けうるのは仕様どおり）
11. 閉じた項目をまたいで広く選択してコピー → 貼り付けると、見えていた文字だけが入る

**バージョン情報・ライセンス（§7）**
12. バージョン情報に版（0.1.0）・著作権表記・ライセンス名が出る。Esc と閉じるボタンで閉じる
13. ライセンスの窓に LICENSE 全文 → 同梱物の一覧 → 各全文が出る。2 回開いても窓は 1 つ

**文言（§13）**
14. キーマップの編集ダイアログに「カーソルグリッドを使う」「カーソルグリッドを編集…」、編集ウィンドウの題が「カーソルグリッドを編集」・案内が「マスをクリックして選ぶ → …」。キーマップの一括切替に「カーソルグリッドを使う」
15. フック欄（詳細表示・簡易表示）に「フックキーをこの構成セット専用にする」「全トリガーを選んでから実行」。出力シーケンス欄のトリガーごとは「選んでから実行」のまま。文字が切れていない
