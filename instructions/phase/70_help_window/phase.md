# phase.md

## フェーズ名

ヘルプの作成（help_window）

## フェーズの目的

メニューバーに「ヘルプ」を新設し、主要機能の使い方と制限の QA を、メインの操作を妨げない別の窓（タブ・2 段の Expander・フィルター）で読めるようにする。主なダイアログに「?」を置いて該当箇所を開く。バージョン情報と、exe 配布を見越した同梱物のライセンス全文を見られるようにする。
**対象は presentation のみ（`presentation/help/` を新設・メニュー・各ダイアログの「?」・`LayoutController` に再同期の窓口 1 つ）+ `keyseq/__init__.py` の `__version__`。JSON スキーマ不変（ヘルプの本文・同梱物の一覧は config ではない同梱データ）。**

- 起票元: ユーザー要望（2026-10-27）。
- 主入力（暫定仕様）: [53_help_window.md](../../history/53_help_window.md)（v0.5・ユーザー確定済）
- モード: **暫定仕様先行モード**。番号対応: phase 70 / 暫定 53 / decisions 70。

## 確定（ユーザー 2026-10-27）

- メニュー「ヘルプ」= 使い方 / よくある質問 / 区切り / バージョン情報 / ライセンス。ショートカットなし（暫定 53 §2・§3）
- ヘルプの窓 = 非モーダル・同時に 1 つ・タブ「主要機能」「QA」・2 段の Expander（既定で閉じる）・位置と大きさは記録しない・フォントに追従（§2・§4.1・§4.2・§4.5）
- フィルター = 入力ごと・AND・NFKC + casefold・自動で開く・ハイライト・タブに件数・空で全表示かつ閉じる（§4.3）
- フィルターの入力欄にフォーカスがある間だけフックを止める（実行中の連続実行が止まるのは受け入れる）（§4.4・§9-7）
- メインの「常に手前」に追従・キーボードUIの「常に手前」は既存の見張りに任せる（切替時の再同期だけ足す）（§4.1・§9-5・§9-6）
- 本文 = 言語別のデータファイル `help_ja.json`・Claude が下書きしユーザーが校正（§5）
- 「?」= ダイアログの子の窓として開く（grab の下で操作できることを実測済）・ダイアログと一緒に閉じる・開くときはフィルターを空にする（§6・§9-2・§9-4）
- `__version__ = "0.1.0"`（以後はユーザーが変更）・「Copyright (C) 2026 池上ノイ (Ikegami Noi)」・GPL v3（§7.1）
- exe 配布の予定あり → 同梱物（外部ライブラリ 11・Python・Tcl/Tk）のライセンス全文を載せる・版の一致を検査（§7.2・§9-3）
