# D3「…」の付与 / 除去の一覧（task_06 の入力・ユーザー確認用）

規則（暫定 51 §3.6 D3）: **開いた先で入力・選択をしてから実行する**メニュー項目・ボタンにだけ末尾「…」を付ける。
すぐ実行するもの・はい / いいえ等の確認だけを出すもの・ウィンドウを開くだけのものには付けない。進行中の表示（「記録中…」）は対象外。D10 の Import / Export は据え置き。
「後」の文字は A・C 項の置換も反映した最終形。
