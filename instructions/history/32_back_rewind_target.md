## §1 目的 / 背景

戻す（`back`）・先頭へ（`rewind`）は今は常に**直前のトリガー**が対象。これに**対象のトリガーを 1 つ固定で指定する**
オプションを加え、直前に何を押したかに関係なく指定したトリガーを戻す / 先頭へ移せるようにする。

## §2 確定事項（ユーザー 2026-10-06）

- **意味 = 対象の固定**: 指定があれば、直前のトリガーに関係なく**指定したトリガー**を戻す / 先頭へ移す
- **指定できるのは 1 つだけ**
- **戻す・先頭への既存規則をそのまま適用**: 参照中の印があれば連鎖の最上段から戻す等（§4.2.6「呼び出しとの関係」）
- **OK 時に拒否**: 未選択・参照先なし / 自分自身 / 戻す・先頭へだけのトリガー
- **一覧の表示**: `[back] → f5` / `[rewind] → f5`
- **キー変更の追従**（v0.3 で確定・旧 Q1）: 対象のトリガーのキーを変えたら `target` も新しいキーへ書き換える
  （呼び出しの `target` と同じ条件〔§4.1: 変えた行が変更前のキーで有効な行だった場合だけ〕・書き換えたシーケンスは未保存扱い・
  その位置・周回・履歴は消さない）。削除では書き換えず、参照が残って「参照先なし」になる（呼び出しと同じ）
- **参照先なしの表示**（v0.3 で確定・旧 Q2）: 呼び出しの表記に合わせる（§6）
- **判定の順序**（v0.3 で確定・Codex 敵対的レビュー）: 待機中・処理中・一時停止中の検査と 2 回押しによる破棄を先に済ませ、その後で戻す段が無ければ戻さない。
  このとき**一覧の選択は対象へ移さない**（現行どおり・案 A。使ってみて不便なら「破棄したら選択を移す」案 B を再検討する）

## §3 データ

- `back` / `rewind` に任意キー **`target`**（トリガーキー・1 つ）を加える。**キーが無ければ従来どおり直前のトリガー**（既存データは移行しない）
- `target` の扱いは呼び出しと同じ: trim のみで保存（小文字化しない）・照合は `normalize_key_name`
- ダイアログはチェック ON で `target` を書き、OFF なら書かない（結果を組み立て直すため、既存の `target` は消える。呼び出しの `all` と同じ流儀）
- `target` キーがあるが空（読込で非文字列も空になる）→ **直前のトリガーへ落とさず**、実行時は「戻す対象のトリガーがありません」（§4）。表示は §6
- 複製・貼り付けは `target` を含めて写す（既存の写し方のまま）。別の一覧へ貼れば、その一覧で解決し直される

## §4 実行時

- **対象の決定**: `target` があれば、押したトリガーと**同じトリガー一覧**（アクティブな一覧）の `target` のキーの**有効な行**（§4.1・重複でグレーの行は使わない）を対象 T とする。
  `target` が無ければ従来どおり直前のトリガー
- 以降（戻すの起点〔参照中の印〕・まとめて戻す・先頭へ・待機中の拒否・処理中の無視・一時停止中の 2 回押し・戻した対象の選択）は**すべて T に対して現行どおり**
  - 2 回押しの控え（§4.2.10）の「対象のキー」も T（控えは対象の identity で持つため現行の仕組みで満たされる）
  - **判定の順序**（§2）: 待機中の拒否・処理中の無視・一時停止中の 2 回押し（2 回目で破棄）を先に行い、その後で戻す段を探す。
    戻す段が無い（一度も押していない・戻し切った・位置変更や編集で消えた）なら何も戻さず、メッセージも出さず、一覧の選択も移さない
    （例: 一度も押していない T を連続実行し先頭の file_line の読込中に一時停止 → 1 回目は通知・2 回目は破棄だけして終わる）
  - T の一番上の行のアクションが空でも、一覧に行があれば対象にする（状態に対して通常どおり戻す / 先頭へ。実質何も起きない）
- **対象が無いとき**（`target` の行が一覧に無い / 空 / 自分自身〔手編集・貼り付けで生じる〕）は既存の「戻す対象のトリガーがありません」を出して何もしない
- `target` が戻す・先頭へだけのトリガー（手編集・後からの編集で生じた）でも実行時エラーにはしない（T の状態に対して通常どおり戻す / 先頭へ。戻す・先頭への押下は履歴を積まないため実質何も起きない）
- 停止 / トグル / 直接切替キーと重なってグレー表示のトリガー（§4.1）も対象にできる（キー入力を経ないため・呼び出しと同じ）
- **直前のトリガーは変えない**（「戻す・先頭へによる変更は直前のトリガーに数えない」は不変）。指定ありの戻す・先頭へを押しても、直前のトリガーは以前の値のまま

## §5 編集ダイアログ

- system の操作が**戻す / 先頭へ**のとき、チェックボックス「**対象のトリガーを指定する**」と対象のドロップダウンを出す
  - ドロップダウンは**呼び出し先のドロップダウンを流用**（同じ候補: 同じトリガー一覧・読み取り専用・自分自身は出さない・`キー: ラベル`・グレー表示も出す・重複でグレーの行は出さない）
  - **チェック OFF の間はドロップダウンをグレー（選べない）**。既定 OFF（新規追加でも OFF）
  - 呼び出しの注記（間隔）・「一括」チェックは出さない。ドロップダウンの見出しは「対象のトリガー」と表示する
  - 同じダイアログで操作を切り替えたとき（呼び出し ⇔ 戻す / 先頭へ）、ドロップダウンの選択（`（参照先なし）` の先頭表示を含む）は**引き継ぐ**（候補が同じため）。
    チェックの ON/OFF は戻す / 先頭への間だけ意味を持ち、切り替えても値は保つ
- 既存の行を開くとき: `target` があればチェック ON で選んだ状態。候補に無ければ呼び出しと同じく先頭に `f5（参照先なし）` を出して選んだ状態（`target` が空なら未選択）
- **OK 時に拒否**（理由を示して閉じない・チェック ON のときだけ検査・呼び出しの検査とは別の判定で、循環・深さは見ない）:

| 状態 | 文言 |
|---|---|
| 未選択 | 対象のトリガーを選んでください |
| 参照先なし（`（参照先なし）` のまま OK） | 対象のトリガーがありません（f5） |
| 自分自身 | 自分自身は指定できません |
| 戻す・先頭へだけのトリガー | 戻す・先頭へのトリガーは指定できません |

  - 検査は**この行を保存するときだけ**（他の操作で生じた不整合は §4 の実行時の扱いに任せる・呼び出しと同じ流儀）
- 単独登録の制限（§4.6）は `target` の有無に関係なく現行どおり

## §6 一覧の表示

- 指定あり: `[back] → f5` / `[rewind] → f5`（キーは正規化後の小文字・ラベルは出さない）
- 参照先なし（一覧に無い・削除された）: `[back] → f5（参照先なし）` / `target` が空: `[back] → （参照先なし）`（呼び出しの表記に合わせる・§2）
- 一覧で解決しない経路（解決関数なし）は、`target` があれば `[back] → f5`・空なら `[back] → （参照先なし）`
- 指定なし: 現行どおり `[back]` / `[rewind]`
- 省略表示の「次に実行」の要約・呼び出し先の表示枠も同じ表示名を使う（正本 §4.6「省略表示の要約も同じ表示名」に従う）

## §8 受け入れ条件（ドラフト）

1. 戻す / 先頭への追加・編集でチェックとドロップダウンが出て、OFF でグレー・ON で選べる。操作の切替で選択とチェックを保つ（§5）
2. ON で OK すると `target` が保存され、OFF なら `target` が書かれない（§3）
3. 未選択・参照先なし・自分自身・戻す / 先頭へだけのトリガーは §5 の文言で OK 時に拒否。下流の連鎖が深い・呼び出しを含むトリガーは拒否しない（§5）
4. 指定ありの戻す / 先頭へは、直前のトリガーに関係なく指定先に効く。参照中の印・まとめて戻す・待機中・処理中・2 回押しは T に対して現行どおり（§4）
5. 指定先が無い・空・自分自身なら「戻す対象のトリガーがありません」（§4）
6. 指定ありの戻す / 先頭へで直前のトリガーが変わらない（§4）
7. 一覧・省略表示の要約・呼び出し先の表示枠の表示が §6 のとおり
8. `target` の無い既存データは従来どおり動く（§3）
9. 対象のキー変更で `target` が追従し、位置・周回・履歴は消えない（§2）
10. 履歴の無い T を連続実行し先頭の file_line の読込中に一時停止 → T を指定した戻すは 1 回目で通知・2 回目で破棄だけし、選択は移さない（§4）

## §9 スコープ外（本フェーズでやらない）

- 複数のトリガーの指定
- 「直前のトリガーが指定先のときだけ動く」という制限の意味（ユーザー判断で「対象の固定」を採用）
- 省略表示での編集（省略表示はシーケンスの編集を持たない）
