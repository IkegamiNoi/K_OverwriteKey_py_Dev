# key_input.md — キー入力・フック仕様

## 7. キー入力・フック

### 7.1 グローバルフック

* keyboard によるグローバルフックを必須とする
* `suppress=True` を使用する（元入力を抑制して置換する）
* suppress の副作用を常に考慮する

### 7.2 フックの停止制御

* 停止キー（hook_stop_key）でフックを停止できる。停止トリガーも単キー
* UI 編集中（キャプチャ・ダイアログ等）はフックを停止する（**ネスト対応**: 多重に
  停止要求が重なっても、すべて解除されるまで再開しない）

### 7.3 トリガー

* トリガーは単キーのみ
* トリガーの重複は禁止（停止キーとの重複も含む）

### 7.4 キーキャプチャ

* 停止キー / トグルキーのキャプチャは相互排他とする
  （`SingleKeyCaptureController` が担当。現状は `codebase_map.md` を参照）

### 7.5 安全ルール

* フック暴走を起こさない（暴走防止最優先）
* keyboard の例外は必ず吸収する
* フック処理を UI と競合させない。UI 更新は `after()` で UI スレッドへ委譲する
