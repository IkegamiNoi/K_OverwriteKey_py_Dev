#### 5.8.5 確認ダイアログ

* **子ファイル一覧**: dirty な子を行として並べ、行ごとに 保存 / 別名保存 / 保存しない を選ぶ。
  dirty な子が無ければダイアログを出さない。キャンセルすると**1 ファイルも書かない**。
  トリガーセットの行は**実体ごと**に出し、表示名に親キーマップの表示名を含める。出力シーケンスの行も表示名でキーマップが分かるようにする（phase 34）
* 再計算後の上書き確認の対象となる「保存」行は、**ユーザーが選んだ（確定した）アクションが保存の行**
  （既定アクションではない）。選択が無い行だけ既定アクションに従う
* **依存確認**: 子の別名保存で親ファイルの保存先の記録が変わり、親ファイルの保存が必須になったとき
  （§5.8.6）に提示する。
  * 親ファイルの共有状況が**「単独所有」「新規作成」なら確認を出さず自動保存**し、保存完了メッセージで事後通知する
  * **共有状態の分類名「所有元不明」「別の親ファイル」「共有中」のときだけ 4 択**（保存 / 別名保存… / 保存しない / キャンセル）を
    提示し、**既定ボタンは別名保存**とする。キャンセルは一覧へ戻る
  * 依存が発生しない経路（親ファイルの保存先が未作成で既定計画により普通に書かれる等）では通知しない
* **再計算先の上書き確認**: 親ファイルの保存先が変わると子の既定保存先も再計算される。
  再計算後のパスに既存ファイルがあり、共有状況が「単独所有」以外の**「保存」行**だけを対象に、
  行単位で上書き確認を出す（0 件なら確認も出ない）。選択肢は
  **上書き / 別名保存… / 保存を中止** の 3 択で、
  **既定は別名保存**。**一覧の再表示・選び直しはしない**
* 別名保存は明示操作であり、その帰結として子の保存先が追随する。**再解決のたびに一覧を再表示しない**

保存先の確認ダイアログの表とボタンごとの結果は `features.md` §4.6「保存先の確認ダイアログ」を参照。表示中はキーボードフックを停止し、閉じ方によらずちょうど 1 回解除する。親は呼び出し時点で grab を持つウィンドウ（無ければ App）とし、開いたときの入力先は既定ボタンにする。Enter はフォーカス中のボタンを押し、Tab はボタン間を移動し、Esc は × と同じ選択肢を返す。
