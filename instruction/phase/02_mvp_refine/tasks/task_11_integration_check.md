# task_11_integration_check.md

## 配置層

検証のみ（コード変更は最小修正に限る）

## 目的

`mvp_refine` フェーズの全タスクが完了した後、**全モード遷移と受け入れ条件を総合確認**する。
発見した不整合は最小修正で対応する。

Proposal の Phase 6「仕上げ確認」に相当。

---

## 確認内容

### A. モード遷移の全件確認

| 遷移元 → 遷移先 | キー | 期待 |
|---|---|---|
| NORMAL → EDIT | Enter（選択ノードあり）| 編集オーバーレイ表示 |
| EDIT → NORMAL | Ctrl+Enter / Esc / ダイアログ外クリック | 編集確定 / キャンセル |
| NORMAL → VIEW | V | ビューモード遷移 |
| VIEW → NORMAL | Esc / Space / クリック | 復帰（Space / クリックは選択 + 復帰）|
| VIEW → EDIT | Enter（着地作成成功時）| 着地作成 → 編集 |
| NORMAL → GRID | G | グリッドモード遷移 |
| GRID → NORMAL | Esc | 復帰 |
| NORMAL → CUSTOM_CREATE | N | カスタム作成 |
| CUSTOM_CREATE → NORMAL | Esc / Enter（確定）| 復帰 / 作成 |
| NORMAL → CONNECT | C | 接続 |
| CONNECT → NORMAL | Esc / Enter | 復帰 / 接続確定 |
| NORMAL → HELP | F1 | ヘルプ表示 |
| HELP → NORMAL | Esc / F1 | 閉じる |

### B. 受け入れ条件の確認

key_input.md / features.md の受け入れ条件を 1 つずつ確認:

#### キー操作
- 通常モード: 矢印選択、WASD クイック作成、N / C / V / G / F1 / Ctrl+S / Ctrl+O / Ctrl+N
- 編集モード: 通常文字入力、Ctrl+Enter、Esc、ダイアログ外クリック
- ビューモード: WASD / Shift+WASD / R / F / Space / Enter / Esc
- グリッドモード: 軸 / スコープ / ライン / 間隔変更 / Esc

#### 表示とグリッド
- グリッドが保存範囲に依存せず描画される
- 縮小時にグリッド線が適切に消える
- ノード / 接続線の描画は維持される
- 端でノード生成すると保存対象グリッドが自動拡張される

#### マウス操作
- 通常モードのマウス操作（パン / ズーム / クリック選択）が無変更で動作
- ビュー / グリッドモード中もマウスのパン / ズームが利用可能
- ビューモード中のクリックはノード選択 + 通常モード復帰
- グリッドモード中のクリックは no-op

#### UI
- 現在モードがフッターまたは UI で視認可能
- key_guide / help_dialog が新キーマップと一致

### C. 既存挙動の維持確認

- 既存の保存ファイル（layout.json）が読み込める
- 保存 → 読込のラウンドトリップが成立する
- 既存のノード操作（選択移動 / 編集 / 削除）が動作する

### D. パフォーマンス

- 大きく拡大 / 縮小しても描画が破綻しない
- 大量ノード（例: 100 個）でも操作レスポンスが許容範囲

## 注意事項

- 不整合発見時はまず原因を切り分け、それが本タスクで直すべきか別タスクに切り出すか判断

- 修正は最小差分。追加リファクタは厳禁
