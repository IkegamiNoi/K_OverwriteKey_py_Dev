# task_13_input_handling.md

## 配置層

presentation

## 目的

入力処理を実装する。

## 実装内容

* キーボード入力の受信
* マウス入力の受信
* ホイール入力の受信
* 選択ノード状態の管理
* `key_input_policy.md` に従ったアクション変換の入口作成
* application 層ユースケース呼び出し
* パン / ズーム入力の処理

## 要件

* 入力イベント内に業務ロジックを直接書かない
* キー入力仕様は別ファイル前提で実装する
* 表示操作とデータ操作を分離する

## 完了条件

* 入力に応じて処理が動く
* キー操作・マウス操作・ホイール操作が分離されている
