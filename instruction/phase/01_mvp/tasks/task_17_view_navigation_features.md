# task_17_view_navigation_features.md

## 配置層

presentation

## 目的

スクロール・パン・ズームの実用機能を実装する。

## 実装内容

* スクロールバー連携または同等の表示移動手段
* マウスホイールによる表示移動
* パン操作
* ズームイン / ズームアウト
* ズーム倍率リセット
* 選択ノードへのフォーカス移動
* 全体表示の基礎

## 要件

* ViewState を使って実装する
* レイアウトや構造データは変更しない
* ヒットテストがズーム後も正しく機能する

## 完了条件

* 画面外に広がるマップを操作できる
* 拡大縮小後も選択や描画が正しく機能する
