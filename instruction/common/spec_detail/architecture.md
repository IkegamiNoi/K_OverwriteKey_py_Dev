## 3. アーキテクチャ方針

### 3.1 採用アーキテクチャ

本ツールはオニオンアーキテクチャを採用する。

### 3.2 依存ルール

* 外側の層は内側の層に依存してよい
* 内側の層は外側の層に依存してはならない
* domain 層は PySide6 を含む UI 実装に依存してはならない
* infrastructure 層は domain/application のインターフェースに従って実装する
* presentation 層は application 層を通じて操作を実行する

### 3.3 各層の責務

#### domain

* エンティティ
* 値オブジェクト
* 純粋なドメインルール
* グリッド制約
* ノード配置制約
* 接続構造制約

#### application

* ユースケース
* 操作のオーケストレーション
* クイック作成
* カスタム作成
* 編集開始・確定・キャンセルの制御
* 表示更新に必要な問い合わせ用サービス

#### infrastructure

* JSON 保存 / 読込
* ファイル I/O
* 設定ファイル読込
* 将来的な永続化差し替え実装

#### presentation

* PySide6 による UI 構築
* キャンバス描画
* 入力イベント受信
* ビュー変換
* スクロール / パン / ズーム
* ステータス表示
* キーガイド表示
