# app_overview.md

## 概要

本ツールは、キーボード主体で高速にマインドマップを構築し、グリッドベースのレイアウトにより視覚的に整理された状態を維持するためのデスクトップアプリである。

## 主要概念

- **ノード**: 一意ID付き。必ずグリッド交点上に存在。1交点1ノード。
- **グリッド**: 行×列で構成。各行・列の間隔は独立設定可能。順序変更可。
- **接続**: ノード間の構造データ。描画時に自動生成。
- **ビューポート**: offsetX / offsetY / scale を持つ表示状態。presentation層で一元管理。
- **座標系**: グリッド座標 → ワールド座標 → 画面座標の変換と逆変換が必須。

## 実装前提

- 実装言語は Python とする
- GUI ライブラリは PySide6 を使用する
- アーキテクチャはオニオンアーキテクチャを採用する
- キー入力の詳細方針は `common/spec_detail/key_input.md` に従う
- ビューポートの詳細方針は `common/spec_detail/viewport.md` に従う
- 描画はキャンバスベースで行う
- 画面外へ広がるマップに対応するため、スクロール・パン・ズームを実装対象とする

## 基本方針

- 思考入力はテキストエディタのように行う
- レイアウトはグリッド単位で制御する
- 接続線は構造データから自動描画する
- 表示範囲の移動と拡大縮小はビュー変換として扱い、保存対象のレイアウトデータとは分離する
