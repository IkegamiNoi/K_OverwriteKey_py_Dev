# レビューポリシー

各タスクで別視点レビューを必ず1回実施する。未実施のタスクは未完了とする。
問題があれば修正してから完了とする。エージェントの使い分けは `.claude/rules/agent_selection.md`。

## ■ レビュー観点（5観点）

- 仕様適合性（仕様逸脱がないか）
- 依存方向
- 責務分離
- 不要変更の有無（過剰実装を含む）
- チェック漏れの有無

## ■ 想定外の先行実装がある場合の追加観点

- 現在タスクの要件達成に本当に必要か / 採用してよい範囲か
- 責務分離・依存方向を壊していないか / 後続タスクの先取りになっていないか
- 保留すべき変更を誤って取り込んでいないか

判定は **採用 / 修正して採用 / 保留 / 除外** で整理する。後続タスク相当の実装が存在しても
自動で完了扱いにせず、現在タスクの要件確認・チェック・レビューを通過したものだけ完了とする
（手順詳細は `instructions/common/rules_detail/task_execution.md`）。

## ■ 仕様変更が必要と判断した場合

仕様書（`instructions/common/spec_detail/*.md`）との乖離や再検討の必要を発見したら
`.claude/rules/spec_change_workflow.md` に従う:

- レビュアーは独断で仕様書を修正・無視しない
- 「仕様書側で再検討推奨」項目として報告に明記する
- 採否判断は必ずユーザーに委ねる
