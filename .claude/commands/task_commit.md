---
description: 完了したタスクの成果をタスク単位で git コミットする
---

完了判定を出したタスクの成果一式を、タスク単位の 1 コミットとして作成してください。
このコマンドはコミット作成のみを行う。ファイルの更新は行わない
（`.claude_data/state/session.md` の更新は `/save_state` の責務。**先に `/save_state` を済ませてから**
このコマンドを実行し、更新済み state をコミットに含める）。

## 前提条件（満たさない場合はコミットせず報告のみ）

- 対象タスクが完了判定済みであること（チェック・レビュー通過。`.claude/rules/task_execution.md` の完了判定）
- 仕掛かり中（WIP）の状態でこのコマンドを使わない

## 手順

1. `git status --porcelain` で変更一覧を確認する
2. 変更を「現在タスクの成果」と「それ以外」に仕分ける
   - 現在タスクと無関係な差分・出所不明の差分は**コミットに含めない**
     （`.claude/rules/anti_patterns.md` / `task_execution.md` の「想定外の先行実装」の扱いに従い、
     未判定のものを混ぜない。発見した場合はユーザーへ報告する）
3. 以下を明示的に `git add` する（`git add -A` は使わない）
   - タスクで変更・作成したファイル
   - `.claude_data/state/session.md`（更新済みのもの）・変更があれば `decisions.md`
   - 進捗を反映した `instructions/phase/current.md`・タスク定義ファイル
4. コミットメッセージは以下の形式
   - `task_NN: <タスク内容の一行要約>`（例: `task_03: 入力コントローラのキーバインド実装`）
   - フェーズを跨いで採番が重複する場合は `task_NN(<phase>): ...` とする
5. コミットのみ行い、**push はしない**

## 報告

コミットハッシュ・メッセージ・含めたファイル数を 1〜2 行で出力する（トークン節約）。
コミットに含めなかった差分がある場合はその旨と理由を添える。

## 注意

- 自動保存モード（`instructions/save_mode/` の auto_save 系設定）では、Stop hook がタスク完了を
  検知した際に `/save_state` に続けて本コマンドの実行を促す。手動保存モードでは任意実行
- タスク完了以外の区切り（重要判断・中断など）では state 更新（`/save_state`）のみでよい
