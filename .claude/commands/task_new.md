現在のフェーズのタスク定義ファイルを起票してください。
本スキルはタスク定義の**書き方**（ファイル書式）を規定する。タスクの**進め方**（実行プロセス・
完了判定・報告）は `.claude/rules/task_execution.md`、レビュー観点は `.claude/rules/review.md` が
正本（本書に重複記載しない）。

## 前提確認（起票前）

1. フェーズの `phase.md`（と暫定仕様先行モードなら主入力の暫定仕様書）を読み、
   このタスクの位置づけ（phase.md「タスク」一覧の何番か・前後タスクとの境界）を確認する。
2. 対象範囲に必要な既存コードのみ読む（広く読まない・`task_execution.md` タスク開始時）。

## 命名・配置

- `instructions/phase/NN_<topic>/tasks/task_NN_<topic_snake_case>.md`（NN はゼロ埋め 2 桁・
  phase.md のタスク一覧の番号と一致させる）
- 枝番（タスク途中で分岐した補完タスク）: `task_NNx_<topic>.md`（例: `task_05b_...`）
- 再検証タスク（仕様変更起因・`/spec_update` ステップ 6）:
  `task_<親NN>_<連番>_<topic>_recheck.md`（例: `task_01_01_domain_scope_recheck.md`）

## ファイル書式（6 節構成）

```markdown
# task_NN_<topic_snake_case>

## 目的

（何を作る/直すか 2〜5 行。**暫定仕様の §番号 / 正本の節番号を参照**して根拠を示す。
**レイヤ制約を明記**: 「presentation 限定・domain/application 不変・スキーマ不変」等）

## 対象範囲（<限定を見出しに明記。例: application 限定・新規のみ>）

（**変更ファイル単位**で節分けし、各ファイルに何を加える/変えるかを具体的に書く。
クラス/関数名・シグネチャ・振る舞いまで規定できる粒度が目安）

### 設計メモ / 制約

（任意。実装者が迷いそうな判断の根拠・既存パターンの流用元・やってはいけない実装を書く。
分量が多ければ独立節 `## 設計メモ / 制約` にしてもよい）

## 含まない

（**後続タスクへ先送りする項目を必ず明示**し、担当タスク番号を付ける
（例:「メニュー配線（task_03）」）。スコープ外事項も列挙。
= 後続タスクの先取り実装の防止線・`anti_patterns.md` 1）

## 確認

（**実行可能な粒度**で書く: 単体テストの項目列挙 / 静的解析 clean / 既存テスト全 pass /
smoke の確認点 等。「動くこと」のような曖昧表現は不可）

## 完了条件

- 上記確認 pass・**reviewer 採用**（CLAUDE.md レビュー必須の運用形。必ず含める）。
- 実機目視の扱いを明示（本タスクで実施 / task_NN でまとめて実施）。
```

## 書き方の原則

- 1 タスク = 最小差分で完結する単位（複数レイヤに跨るなら分割を検討。
  典型順序: domain → application → presentation → 統合退行 → 正本反映）
- 「対象範囲」に書いていない変更は実装者はやらない前提で書く（曖昧な範囲を残さない）
- フェーズ最終タスク（正本反映）は `.claude/rules/task_execution.md`「フェーズ完了時」の
  チェックリスト項目（昇格・凍結 / decisions_archive / current.md / idea INDEX_done 移動 /
  /refactor_check）を対象範囲に含める
- 確認節の検証コマンドは実在のものを書く（実行コマンドは `.claude/rules/` の言語別ルール参照）

## 付随更新

- フェーズ途中でタスクを**追加**した場合（枝番・recheck 含む）: `phase.md` の「タスク」一覧へ
  1 行追記する。`current.md` へのタスク詳細の記載は不要（書かない）。

## 禁止事項

- phase.md / 暫定仕様に無い要件をタスク定義へ加えること（拡張はユーザー確認が先）
- 後続タスクの内容を対象範囲へ混ぜること（「含まない」へ書く）
- 「含まない」節・「完了条件の reviewer 採用」の省略
- 確認節を曖昧な表現（「正しく動く」等）で埋めること
- 起票したタスク定義を読まずに実装へ着手すること
