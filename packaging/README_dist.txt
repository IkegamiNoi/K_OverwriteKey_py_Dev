PyInstaller のブートローダには GPL の例外が適用されます。第三者ライセンスはヘルプの「ライセンス」画面で確認できます。
sources/ には GPL / LGPL の依存ライブラリ mouseinfo と pynput のソースアーカイブを同梱しています。
pynput を変更版に差し替えるには _internal/pynput/ を変更版のファイルで置き換えてください。
_internal/ の VCRUNTIME140.dll・VCRUNTIME140_1.dll は Microsoft Visual C++ ランタイムの再頒布可能ファイルで、Microsoft のライセンス条項が適用されます。本ソフトウェアを再頒布する場合は、Microsoft の再頒布可能コードに関する条件（ヘルプの「ライセンス」画面の Python の項）に従ってください。
設定は実行ファイルの隣の config/ に保存されます。
