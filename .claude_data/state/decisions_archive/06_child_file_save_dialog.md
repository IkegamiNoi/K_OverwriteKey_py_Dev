  ダイアログを出さないことのみ規定）。ズレていたのは task_06 目視チェックリスト #2 の文言。
  → §3 末尾に「変更なし保存でも親・起動設定・未作成の子は書かれ、完了ダイアログは出る」を明記。**修正しない**。
- **⑤ダイアログの見た目**（10 行以上で横はみ出し）→ **Phase β 内の追加タスクで対応**（task_06 の当初方針
