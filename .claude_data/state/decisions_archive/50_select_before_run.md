## 確定した設計判断（ユーザー）

| # | 判断 | 採らなかった案と理由 |
|---|---|---|
| 1 | フォーカス = 一覧の選択。選ばれていないトリガーの 1 回目は選ぶだけ・2 回目で実行（時間の制限・控えなし） | 時間の制限 = 確かめる時間を縛る |
| 2 | 全体（構成セット・フック欄）とトリガーごと（シーケンス・シーケンス欄）の 2 か所。どちらかが ON なら対象 | 全体だけ / 個別だけ = 使い分けができない |
| 3 | 対象はトリガー一覧のトリガーだけ（直接置換・停止系・呼び出しで呼ばれたものは対象外）。戻す・先頭へだけのトリガーも対象外 | 戻す・先頭へも対象 = 一時停止中の破棄の 2 回押しと重なる |
| 4 | 処理中・再開・自身の保留の判定は従来どおり先。選ぶだけは何も処理しない押下にだけ効き、実行状態を一切変えない（一時停止中のものを捨てない・他の待機を取り消さない） | — |
| 5 | 1 回目は一時メッセージ「<K> を選びました（もう一度押すと実行します）」 | — |
| 6 | 単発の待機が明けたとき、待機の間に選択が変わっていたら選び直さない（手段によらず・機能の ON / OFF によらない既存挙動の変更・v0.4） | 選ぶだけの押下のときだけ = 一覧のクリックで同じ問題が残る |
| 7 | 選ぶだけにしたキーは離すまでのリピートを無視（v0.4・Codex 敵対的 high）。トリガー以外のキーの押下では無視は終わらない（runner に届かないため・Windows では体感差なし・v0.5） | 未割り当てキーでも終わらせる = フックの経路を広げる |
| 8 | 待機明けの判定は保留に控えを持たず、待機明けの時点の選択で判定（v0.5・統合レビュー M1 を実装を正として文言を確定） | — |
| 9 | 名称「確認して実行」・フック欄は個別指定の下の行・シーケンス欄は間隔の下・省略表示の全体のチェックは操作可（v0.6・実機目視 2026-10-08） | 右隣 = +3 で既にはみ出す・省略表示は無効表示 = 切り替えのたびにフル表示へ戻る |
| 10 | `target` の無い戻す・先頭への対象 = 押した時点で一覧に選ばれているトリガー。使えなければ直前のトリガー（v0.6・idea_39 の中心部分の取り込み） | 直前のトリガーのまま = 見えている対象と効く対象がずれる |
| 11 | 戻す・先頭へだけのトリガーは押しても自身を選ばない（v0.6・Codex 敵対的 high: 2 回押しの 2 回目で対象がすり替わる） | 自身を選ぶ（従来）= 2 回目が直前のトリガーへ落ちる |
| 12 | フォント +3 でフル表示の最小の高さが画面に取れる高さを超え（931 > 927 px）、シーケンス欄のボタン列の最下段の「確認して実行」が数 px 切れるのは受容（2026-10-09・再実機目視） | ボタン列の余白を詰める = 効果が測るまで不明・テストと再目視が増える |
| 13 | 「直接クリックで選んだトリガーが戻すの対象にならない」は再現せず（コード上も選択は同じ値）。直前のトリガーの廃止・戻す系を直前の実行に記録しない・戻す段が無いときの無反応は idea_39 の残りへ（2026-10-09） | phase 50 で v0.7 = フェーズ末の再レビュー・再目視が増える |
