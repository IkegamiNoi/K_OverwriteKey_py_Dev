| 3 | 矢印は枠を選んでいる間だけ suppress | 常に suppress = 選択なしでアプリのスクロール等に使えない |
| 4 | 操作キーは keymap ごとに各 1 つで付け替え可・**Esc = 戻る / num enter = クリックは固定**・右クリック = Shift + クリックのキー | 各操作 2 キーまで（v0.2）= 2 つ目を空にする UI と Esc の取り込みが要る（ユーザー案「付け替えは BackSpace 側だけ」を一般化）/ 右クリック専用キー = 修飾キーの記録・判定が広がる |
| 5 | 重なり: 編集の窓の OK では拒否・既存 / 手編集は「枠のキー > 操作キー」の優先順位で解決（読込時の固定予約は修飾キーだけに縮小） | 読込時も拒否・既定へ戻す = 既存・手編集のデータの扱いが面倒（ユーザー） |
| 6 | 編集の窓はドラッグ中に関係する枠（段の境界 = 上下 2 段の全部 / 列の境界 = 左右 2 枠）の中心へ十字・離したら消す | — |
| 7 | 編集の窓の十字の色 = その枠の線の色（task_06・実機で違和感なし） | 枠の窓と同じ黄に固定 = 編集の窓では黄が「選んでいる段」を表すので紛らわしい |
| 8 | 統合レビューの採否（task_06）: 固定キーと未編集の画面の枠のキーの重なりを OK で拒否（task_06a）/ 手編集の操作キーと矢印の重なり・別名は受容 / 画面名の表示・4 経路の往復テストは見送り | — |
