### 【起票時】方式 → **キーマップ従属**（タブ方式は不採用・ユーザー確定 2026-09-24）

- トリガー一覧（とそれに従属するシーケンス）をキーマップに従属させ、「キーマップ＝モード」として一括で切り替える。
  タブ方式はタブ切替の仕組みがキーマップ切替と重複するため採らない。
- 共通トリガー層は作らない → [idea_36](../../instructions/backlog/idea_36_common_trigger_layer.md) へ起票のみ。
  将来は新キー（`common_trigger_set_path` 等）で持ち、keymap_set の `trigger_set_path` を転用しない（意味変更禁止）。
- 参照は **keymap ファイル**に持たせる（従属関係に合わせる。現行の trigger_set → sequence の共有構図を 1 段上に適用）。
- 旧形式はアクティブなキーマップにのみ移行。後方互換は「古い JSON を読める」ことのみ（前方互換は不要）。
- キーマップは常に 1 つ以上・2 つ目以降の追加は切替キー必須・一覧の選択 = アクティブ化（未保存にしない）・
  連続実行中は切替不可・置換 > トリガー（編集時は双方向で重複禁止・読込時の重複はグレー表示）・Import / Export も対象。
- 「通常トリガー無効化」を **「キーマップ一時停止」⇔「キーマップ再開」** へ改名（A 案・関連表示も揃える・内部名は変えない）。
