| 1 | ステータス欄を削除しタイトルへ（通常 = レイアウト名 / 編集中 = キーと Esc の案内）。凡例・右クリックの案内は出さない | 欄を残す = 静的な説明が大半で場所を取る / 完全削除 = 編集中の案内が消える |

| 6 | **マウスのボタンが押されている間は補正しない**（v0.4・task_02 の実機目視 NG〔縮めると大きく・広げると小さく〕） | — （原因 = ドラッグ中に止まった間の補正が Windows に上書きされ基準がずれる） |
| 7 | 他アプリのドラッグ中は補正が延びる・`Alt+Space` のキーボードでのサイズ変更は保証外（v0.4 Codex 敵対的の受容） | WM_ENTERSIZEMOVE で判定 = スコープ外の深い介入 |
