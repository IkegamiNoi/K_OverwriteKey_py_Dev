### 【task_03d・03e 実機目視 NG の計測】暫定 46 v0.5 = 離した直後の押下は押し続けの続き（2026-10-20・ユーザー確定）
- 原因（デバッグ出力）: 長押しの途中でフックの処理が約 30 ms 詰まり、OS のリピート 2 回を離しの 2 回組と取り違え → 次のリピートが「押した」→ その次が案 A の「離した」…と連鎖し、リピート 2 回ごとに置換先が出続けた（v0.4 §3.3 の「1 回余分」の想定外）。123 で届く普通のキー（リモート実行）の計測は対象外と切り分け。
- 規則: 「長押しの途中の 2 回組」または「案 A の片方」の「離した」から 16 ms 超〜60 ms 以内の押下は続き（押している状態へ戻す・`handle` を呼ばない・決定は元のまま・「押した」の時刻は置き直す・押下状態は戻さない）。退けた案: リピートありを正式化 / 色を緑に戻してこの動きを受容。
- Codex 敵対的 2 回: 1 回目 high（0.1 秒の連打が消える）→ 対象を絞る / medium（400 ms をまたぐ 2 回組で押したまま）→ 2 回目 high（長押しの後の連打が全て消える）と合わせ「押した」の時刻の置き直しで解消。受容: 長押し・片方の取りこぼしの後 60 ms 以内の押し直しの 1 打 / リピートの間隔を 60 ms より遅くした設定での連鎖。
- 実機目視で出た IME の切り替えは未特定（計測では 241 / 242 は全て抑止・ユーザーが操作を後で伝える・暫定 46 §9 #7）。色の最終判断は task_03f の実機目視の後。
- 進め方: task_03f（状態機械を v0.5 に）→ 実機目視のやり直し → task_04。
